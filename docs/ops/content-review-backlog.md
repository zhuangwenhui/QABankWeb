# 内容审计:结论与遗留(2026-07-26/27)

对全库 **358 道**题解做了一轮数学正确性审计:逐题独立验算,每条发现再由两个独立视角
(自己重算 / 尽力驳倒)对抗式复核,只有两个视角都认为成立才动手改。

| 阶段 | 规模 | 结果 |
|---|---|---|
| 逐题验算 | 358/358 道,无遗漏 | 提出 150 条发现 |

改动落库两批:**37 处答案级/推导级错误**(28 道题),**102 处轻度问题**(91 道题)。
另修了一处我自己上一轮造成的回归(见下)。

验收拦下的 5 条值得记一笔 —— 它们说明这道关卡不是形式主义:

- **q350**:修订本身引入了**新的**复杂度错误(完全图上 $n$ 次 Bellman–Ford 是 $O(n^4)$
  不是 $O(n^3)$),已改为只提 Floyd–Warshall 并说明 Bellman–Ford 的真实代价。
- **q329**:修订把 $c_2$ 的分母写成 $(x_2-x_1)(x_3-x_2)$ —— 那是 $c_2$ 与 $c_3$ 因子的
  拼接,整体差一个负号,恰好是该警告框本身要防的符号错误。已重写。
- **q100 / q324**:题面转写缺料/写错,但补丁没碰题面。已逐条对照原卷图片订正(见下)。
- **q201**:误报 —— 该题题面字段只是转载声明,正文在日文轨的 `## 問題文` 里,
  是我的材料包把它复制进「题面」小节才显得重复。

## 二、动到题面的三处(都对照过原卷图片)

题面是入试原题的转写,改它就可能变成另一道题。只有当出错的那段本身是**录题者自撰
或漏抄**的内容时才动,且逐条比对原图:

- **q265**:照图整理的边表把 $e\text{–}j=3$ 抄成了 $e\text{–}i=3$。按题面字面跑
  Dijkstra 得到的最短路唯一,与题解给出的三条直接矛盾;按图重算才是三条。
- **q324**:$f_{aba}(bababababa)$ 多抄了一组 `ba`,原卷是 8 字的 $f_{aba}(babababa)$。
  两轨题解与采点原本就以 8 字版为正解,题面与标准答案自相矛盾。
- **q100**:题面只写「用推论规则定义 ND」却没抄规则表。原卷完整排印了 10 条规则,
  其中**无前提公理** $\Gamma\vdash(A\vee(A\supset B))$ 是 (2)(c) 可证的关键 ——
  缺了它,(2)(c) 在纯直觉主义正片段里根本不成立。已按原图补全。

## 三、遗留:11 条存疑(两个复核视角意见相反,需人工裁决)

这些都没有改动。每条都是「一个视角算出它确实错、另一个视角给出了具体的辩护」,
分歧点已写在下面,自行判断即可。

| 题号 | 争点 | 两方各自的理由 |
|---|---|---|
| q262 | 設問3(2) 要求给出 4 个有序对,两轨都只写了部分并标「待补」 | 图源只到第 1 页、図2 未采集是事实;分歧在于这算「漏答」还是「题源不全」 |
| q87 | 把 $zf'/f$ 说成可套用本题结论 | 一方:$zf'/f$ 不是椭圆函数,套用会得出错的结论;另一方:该条标题写的是「同型の議論の応用」,指的是同一手法而非同一结论 |
| q131 | 中文结论框列了 (1)(2)(4) 独缺 (3) | 一方:与日文轨不一致;另一方:(3) 是证明题,中文结论框收的本就只是三个求值结果 |
| q147 | 采点「典型失点」说连续性是 (2)(3) 的前提 | 一方:(2)(3) 的算法根本不走积分号下求导;另一方:原文没说是「(1) 的连续性」,按标准读法指的是被积函数的连续性 |
| q235 | 用 $a_n=(-1)^n$ 作「去掉收敛前提就不成立」的反例 | 一方:$(-1)^n$ 的算术平均恰好收敛到 0,见证不了失效;另一方:原文反驳的命题不是这一个 |
| q259 | 尖点处左右单侧斜率写作 $\mp 10f(0)$ | 一方:左右正负颠倒了;另一方:$\mp$ 按数轴左负右正的常规配对读是对的 |
| q273 | $\varphi_*$ 的 $\varphi$ 在中文轨从未定义 | 一方:读者只见过题面的 $\varphi_n$,会误读;另一方:日文轨同句括号里就给了定义 |
| q280 | 「幾何的直観」把 $P,P'$ 说成与原/像平面共面 | 一方:实算 $P,P'$ 都不在各自平面上;另一方:原文没有作出共面断言 |
| q292 | 補題写作 $(E+K)(E-K+K^2)=E-K^3$ | 一方:展开得 $E+K^3$,符号错;另一方:该補題的前提是 $K^3=O$,此时两者都等于 $E$ |
| q311 | 把 $a=-\tfrac12$ 代入声称 $0<a<1$ 的公式作自洽性验证 | 一方:$-\tfrac12$ 不在该区间内,论证不严;另一方:推导处早已写明真实条件是 $1+a>0$ |
| q344 | 称 $f$ 为擬距離(pseudometric) | 一方:$f$ 不对称(实算 $f(A,B)=0.693$、$f(B,A)=9.307$);另一方:原句限定在「常数列的同值类」上,那里确实对称 |
